개인정보처리방침 — 기상미션

English · 한국어

시행일: 2026년 11월 2일

기상미션("본 앱", "당사")은 알람을 끄려면 미션(수학·기억력·흔들기·타자 등)을 완료해야 하는 알람 앱입니다. 본 방침은 앱 사용 시 관련되는 정보를 설명합니다.

당사는 자체 서버를 운영하지 않으며, 본 앱은 계정 가입이나 로그인이 필요하지 않습니다. 알람과 설정은 사용자 기기에 저장되며, 사용자가 직접 백업 파일을 내보낸 경우에만 사용자가 고른 위치에 사본이 생깁니다.

1. 수집하는 정보

당사(개발자)는 사용자로부터 어떠한 개인정보도 수집하거나 전달받지 않습니다. 본 앱은 백엔드 서버나 로그인이 없으며, 알람·설정을 당사로 전송하지 않습니다.

앱 사용 중 생성되는 데이터는 사용자 기기에만 저장됩니다:

  • 알람 시각, 반복 요일, 선택한 미션, 알람음·음량
  • 앱 환경설정(언어, 테마, 코인, 인앱 설정)
  • 사용자가 고른 사용자 지정 벨소리 파일(앱 전용 저장소로 복사)

앱의 저장공간을 비우거나 앱을 삭제하면 이 데이터는 언제든 모두 지울 수 있습니다.

백업 내보내기·복원

설정에서 백업 내보내기를 누르면 알람(시각·반복 요일·미션 등), 기상 기록(성공한 날짜·기상 시각), 데일리 챌린지 도장, 코인·마스코트 보유 내역, 테마·효과음 설정을 JSON 파일 하나로 만들어 사용자가 시스템 파일 저장 창에서 고른 위치에 저장합니다. 복원은 사용자가 고른 백업 파일을 읽어 현재 데이터를 덮어씁니다. 이 파일은 당사로 전송되지 않으며, 클라우드 저장소 등 사용자가 고른 위치에 저장한 경우 그 서비스의 정책이 적용됩니다.

2. 카메라와 사진

현재 버전은 카메라를 사용하지 않으며, 카메라 권한도 요청하지 않습니다. 사진을 촬영·저장·전송하지 않습니다.

3. 광고 (Google AdMob)

본 앱은 연습/메뉴 영역에서 Google AdMob을 사용해 광고를 표시합니다. AdMob은 Google이 제공하며, 광고 게재·측정을 위해 다음 정보를 수집·처리할 수 있습니다:

  • 광고 식별자(Android 광고 ID), 기기 식별자
  • 기기 정보(모델, OS 버전, 언어, IP 기반 대략적 위치)
  • IP 주소 및 광고 상호작용 데이터

이 데이터는 당사가 아닌 Google이 수집합니다. Google 정책을 참고하세요:

  • Google 서비스를 사용하는 사이트·앱의 정보 사용 방식: https://policies.google.com/technologies/partner-sites
  • Google 개인정보처리방침: https://policies.google.com/privacy

EEA·영국·스위스 사용자 동의

필요한 경우, 본 앱은 GDPR에 따라 맞춤 광고 게재 전에 Google의 사용자 메시지 플랫폼(UMP)을 통해 동의를 요청합니다. 동의는 앱을 처음 실행할 때 받으며, 현재 앱 안에는 동의 선택을 다시 여는 메뉴가 없습니다. 선택을 바꾸려면 기기 설정에서 본 앱의 데이터를 삭제하거나 앱을 다시 설치하면 다음 실행 때 동의를 다시 요청합니다(이때 알람 등 앱 데이터도 지워지므로 먼저 백업 내보내기를 권장합니다). 맞춤 광고 설정은 Google 광고 설정(https://adssettings.google.com)이나 기기의 광고 설정(광고 ID 재설정·삭제)에서도 관리할 수 있습니다.

미국 사용자

거주 주에 따라, 맞춤 광고를 위한 개인정보의 "판매"·"공유"를 거부할 권리가 있을 수 있습니다. 동의/거부 양식이 표시되는 경우, 선택은 광고 맞춤설정에 반영됩니다.

4. 권한과 사용 목적

  • 알람 및 리마인더 / 정확한 알람·전체 화면 인텐트: 정확한 시각에 알람을 울리고, 화면이 잠겨 있어도 전체 화면 미션을 표시하기 위함.
  • 알림: 알람·리마인더 표시.
  • 진동, 화면 깨우기, 부팅 시 실행: 알람을 안정적으로 울리고 유지하며, 재부팅 후 예약된 알람을 복원하기 위함.
  • 포그라운드 서비스 / 미디어 재생: 알람음을 계속 재생하기 위함.
  • 다른 앱 위에 표시 / 배터리 최적화 제외: 알람 미션이 다른 앱 위에 확실히 나타나고 시스템에 의해 종료되지 않도록 하기 위함.
  • 실행 중인 앱 순서 변경(REORDER_TASKS): 알람이 울릴 때 기기 기본 알람 등 다른 앱 화면에 가려진 미션 화면을 맨 앞으로 끌어올리기 위함.
  • 방해 금지(알림 정책) 접근(ACCESS_NOTIFICATION_POLICY): 사용 중인 알람 기능 라이브러리가 요구해 선언한 권한으로, 알람이 울릴 때 지정한 알람 음량을 적용하는 데 관련됩니다. 본 앱은 방해 금지 모드 설정을 읽거나 변경하지 않으며, 이 권한을 따로 요청하지 않습니다.

권한은 위 기능에만 사용되며 개인정보 수집 목적으로 사용되지 않습니다.

5. 아동

본 앱은 만 13세 미만 아동(또는 해당 국가의 최소 연령)을 대상으로 하지 않습니다. 당사는 아동의 개인정보를 고의로 수집하지 않습니다.

6. 데이터 보관 및 보안

당사는 서버가 없으므로 사용자 데이터를 보관하지 않습니다. 모든 앱 데이터는 사용자 기기에 존재하며, 앱 데이터를 지우거나 앱을 삭제하면 제거됩니다. 광고를 위해 Google이 처리하는 정보는 Google 정책에 따라 처리됩니다.

7. 사용자 권리

거주 지역(예: EEA/영국의 GDPR, 미국의 CCPA/CPRA)에 따라 개인정보 열람·삭제·처리 제한, 맞춤 광고 거부 등의 권리가 있을 수 있습니다. 개발자는 개인정보를 보유하지 않으므로, 이러한 요청은 주로 Google의 광고 데이터와 관련됩니다(위 Google 정책 참고). 아래 연락처로 문의하셔도 됩니다.

8. 방침 변경

본 방침은 변경될 수 있습니다. 중요한 변경은 위 "시행일"을 갱신하고, 필요한 경우 앱 또는 스토어 등록정보에 반영합니다.
